# homeacc-banks

Фид правил привязки банков для программы HomeAcc (домашняя бухгалтерия).

Фид управляется этим репозиторием: `banks/index.json` перечисляет **все банки
реестра ЦБ** (действующие и закрытые), у каждого записан регномер лицензии и
откуда брать правила. Программа при каждом запуске сверяет локальную папку
`banks\` с фидом и тихо обновляет файлы правил — формы привязки перепроверяются
через интернет автоматически.

## Структура index.json

```json
{
  "v": 2,
  "updated": "2026-10-21",
  "banks": [
    { "id": "yoomoney", "name": "ЮMoney", "regNum": "3510",
      "repo": "simonov-p-a/homeacc-bank-yoomoney" },
    { "id": "pao-sovkombank", "name": "ПАО «Совкомбанк»", "regNum": "963",
      "file": "banks/pao-sovkombank.json" },
    { "id": "makb-premer-zao", "name": "МАКБ «ПРЕМЬЕР» ЗАО", "regNum": "3" }
  ]
}
```

* `id` — латинский идентификатор банка.
* `name` — человекочитаемое название для программы.
* `regNum` — регномер лицензии ЦБ. **Ключ сопоставления**: по нему программа
  находит локальный файл банка — названия у фида и реестра ЦБ разные
  («ЮMoney» против «ООО НКО "ЮМани"»), а номер лицензии один.
* `repo` — отдельное репозиторий банка; в нём `bank.json` с правилами.
  Указывается банкам, которым заводят свой раздел.
* `file` — путь к файлу правил **внутри этого репозитория** — способ держать
  правила у каждого действующего банка без тысячи репозиториев.
* Без `repo` и `file` — банк только перечислен (закрытые: форма не нужна).

## Структура bank.json (правила одного банка)

Форма привязки индивидуальна для каждого банка: шаги инструкции, поля формы
и кнопки описываются прямо в правилах, а код программы лишь рисует их.

```json
{
  "name": "Название банка",
  "regNum": "3510",
  "site": "https://банк.рф",
  "binding": {
    "type": "oauth | manual",
    "steps":   [ { "text": "шаг инструкции", "bold": true } ],
    "fields":  [ { "name": "clientId", "label": "client_id", "placeholder": "…" } ],
    "buttons": [ { "label": "① Регистрация", "action": "register" } ],
    "codeInput": true,
    "authorizeUrl": "https://.../authorize",
    "tokenUrl": "https://.../token",
    "apiBase": "https://.../api",
    "scope": "operation-history",
    "registerUrl": "https://.../new-app",
    "redirectUri": "https://localtest.me:18791/cb",
    "instructions": "Текст инструкции для пользователя"
  }
}
```

* `type: "oauth"` — банк с открытым API: программа сама отправляет привязку
  и загружает операции. Эндпоинты (`authorizeUrl`, `tokenUrl`, `apiBase`,
  `scope`) — обязательны.
* `type: "manual"` — банк без открытого API: в форме показываются официальные
  инструкции и инструмент ручного импорта операций (вставкой строк
  «дд.мм.гггг; сумма; описание»).
* `regNum` — регномер лицензии ЦБ: второй ключ сопоставления с локальным
  файлом банка (важен, если правила вынесены в отдельное репозиторий).
* `steps` — шаги инструкции (каждый — объект с `text`, опционально `bold`).
* `fields` — поля формы (`name`, `label`, опционально `placeholder`, `help`).
* `buttons` — кнопки действий (`label`, `action`: `register` | `auth` |
  `sync` | `open`, опционально `url`, `primary`).
* `codeInput` — показывать ли поле для вставки ссылки с кодом авторизации.

Если у банка нет собственного описания формы — программа подставляет
умолчания для его `type`.

## Добавление нового банка

1. Создайте файл правил: отдельным репозиторием `owner/homeacc-bank-<id>`
   (публичное, в нём `bank.json`) либо файлом `banks/<id>.json` в этом
   репозитории — второй способ проще и не упирается в лимиты GitHub.
2. Добавьте запись `{ "id", "name", "regNum", "repo" | "file" }` в
   `banks/index.json` — **`regNum` обязателен**, без него программа не
   найдёт локальный файл банка.
3. Залейте в `main`.

Программа подтянет правила сама при ближайшей перепроверке.
